# Complete Deployment & Migration Guide: Orvion IntelliAct

This guide covers all the exact steps to launch your new Next.js website using Hostinger for hosting/database and GoDaddy for the domain.

---

## Phase 1: Set Up the Database (Hostinger)
First, we need to create a real database on Hostinger to hold your documents.

1. **Log in to Hostinger:** Go to your Hostinger hPanel.
2. **Navigate to Databases:** Click on **Databases** > **Management** (or MySQL Databases).
3. **Create a New Database:**
   * **Database Name:** Enter a name (e.g., `intelliact`).
   * **MySQL Username:** Enter a username (e.g., `db_user`).
   * **Password:** Create a strong password and save it.
   * Click **Create**.
4. **Copy the Credentials:** Hostinger will usually prefix your database and username with a unique string (like `u123456789_intelliact`). Save the exact **Database Name**, **Username**, and **Password**.
5. **Note the Hostname:** Usually, the hostname will just be `localhost` or `127.0.0.1` when your website is hosted on the same Hostinger account.

---

## Phase 2: Link GoDaddy to Hostinger (Using DNS / A Record)
Instead of changing nameservers, you can keep your DNS management on GoDaddy and just point the **A Record** to your Hostinger server's IP address.

1. **Find Hostinger's IP Address:** 
   * In Hostinger hPanel, go to your **Hosting** dashboard.
   * Look for the **Website IP** or **Shared IP address** on the left sidebar under Account Details. (It looks like a set of numbers, e.g., `193.168.0.1`). Copy this IP address.
2. **Log in to GoDaddy:** Open a new tab and log in to GoDaddy.
3. **Go to Domain Portfolio:** Click on `intelliactind.com` and navigate to the **DNS Management** page.
4. **Update the A Record:** 
   * Find the existing **A Record** with the Name/Host set to `@`.
   * Click **Edit**.
   * In the **Value** (or "Points to") field, paste the Hostinger IP address you copied in Step 1.
   * Click **Save**.
5. **Update the CNAME Record (Optional but recommended):**
   * Find the **CNAME Record** with the Name/Host set to `www`.
   * Ensure it points to `@` or `intelliactind.com`.
*(Note: It can take anywhere from a few minutes to a couple of hours for DNS changes to fully propagate).*

---

## Phase 3: Prepare the Code for Upload
Before uploading, you need to bundle the Next.js app for production. 

1. **Build the App Locally:** Open your terminal in VS Code (in the `Orvion-IntelliAct` folder) and run:
   ```bash
   npm install
   npm run build
   ```
2. **Zip the Files:** Once the build finishes, you need to ZIP the project files to upload them. 
   **IMPORTANT:** **DO NOT** include the `node_modules` folder in the ZIP (it's too large and will break). 
   **DO** include:
   * `.next` folder (this was generated by the build command)
   * `public` folder
   * `lib` folder (specifically ensure `lib/db-mock.json` is there because that's where the migration data lives!)
   * `package.json` and `package-lock.json`
   * `server.js` (Your startup file)

---

## Phase 4: Deploy to Hostinger (Node.js)
Hostinger shared hosting plans often require setting up a "Node.js App" from the panel.

1. **Upload the ZIP:** 
   * In Hostinger, go to **Files** > **File Manager**.
   * Open the `public_html` folder for your domain.
   * Delete the default `default.php` or `index.html` file if it exists.
   * Upload the ZIP file you created in Phase 3 and **Extract** it inside `public_html`.
2. **Set Up Node.js Environment:**
   * Go back to the main Hostinger hPanel dashboard.
   * Search for **Node.js** in the sidebar (usually under Advanced).
   * Click **Create Application**.
   * **Application Mode:** Production
   * **Application Root:** `public_html`
   * **Application URL:** `intelliactind.com`
   * **Application Startup File:** `server.js`
3. **Set Environment Variables:**
   Scroll down to the Environment Variables section in the Node.js app setup and add the database credentials you got in Phase 1:
   * `DB_HOST` = `localhost` (or the IP provided by Hostinger)
   * `DB_PORT` = `3306`
   * `DB_USER` = `your_hostinger_db_username`
   * `DB_PASSWORD` = `your_hostinger_password`
   * `DB_NAME` = `your_hostinger_db_name`
4. **Install Dependencies:**
   * After creating the app, Hostinger provides a button to **"Run NPM Install"**. Click it. This will securely install the `node_modules` on the server.
5. **Start the App:**
   * Click the **Start / Restart** button for the Node.js application.

---

## Phase 5: The Automatic Migration
**You do not need to manually import the documents into MySQL!**

Because you uploaded the `lib/db-mock.json` file along with the code, the very first time someone visits the deployed website (specifically the Employee Portal), the `server.js` will trigger your database code. 

The code will realize the MySQL database is empty, and it will automatically loop through `db-mock.json` and seamlessly insert every single document, PDF, and piece of mock data straight into your new Hostinger MySQL database. 

Everything is completely automated from the code side!
